# 交付记录

日期：2026-10-19（Asia/Shanghai）。项目版本1.0.0。

## 采用的约定

来自用户本次要求及所引用会话“介绍割草游戏”：26个池、每池至少10且本次明确不要恰好10、统一ID多池归属、完整固定五级、等概率二选一、重复升级、满级移出、取消品质与融合、初始3槽、稀少主线扩槽、地球怪兽固定积分、首次行星级1000:1统一换算。

初版实际提供316个唯一技能。每池至少12项；跨池共享数及总名额以`reports/catalog_validation.json`为准，不把一个技能的五级当五个技能凑数。

沿用此前明确26池价格表：意志秘术10000旧积分。历史回复曾另外建议将其涨至100000，但未看到用户确认；因此没有将建议当成既定价格。本次初始3槽优先于历史回复中出现的4槽。

## 为可运行补齐的细节

- 每池不足二选一时退化为单选且保持原价，空池不扣款。
- 收到新技能先入库，由作者显式装备，避免脚本替作者决定构筑。
- 预留3个各加1槽的主线占位事件，未安排具体小说情节。
- 待选候选持久保存、不可取消退款、配置摘要锁定、唯一战斗/奖励编号、精确小数与原始整数账本。
- 能量预算、范围基准、同类上限、控制抵抗、恢复共享窗口及分身约束写入《数值规范》，作为初版固定解释。
- 不把高阶技能抽到等同于立即获得高阶力量。药剂/分身/吞噬归特殊技能，灵魂振幅归掌控者且可跨灵魂池。

## 机制参考

参考经典割草构筑的多投射物、环绕、弹射、回旋、穿透、持续区域，以及防御/闪避/机动分工；所有技能数值均为本项目自设，不复制其他游戏的成长表。取消品质与融合是本项目的既定规则。

- [poncle：Adventures FAQ](https://poncle.games/adventures-faq)：用购买武器加入后续升级候选的方式组织构筑，本项目仅借鉴“有限候选与选择成长”的思路。
- [Brotato社区Wiki：Stats](https://brotato.wiki.spellsandguns.com/Stats)：提供防御、闪避等属性分工的参考。本项目不照搬其护甲公式、职业平衡或具体概率。

这些资料只作为机制设计参考，不作为《吞噬星空》原著设定证据。技能效果本身以本地JSON与数值规范为准。
