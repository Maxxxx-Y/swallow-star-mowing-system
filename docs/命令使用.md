# 命令使用

在项目根目录运行，Python 3.9+，仅支持macOS/Linux（使用标准库文件锁）。不需要联网或安装包。命令错误会返回非零退出码且不写入角色存档。

## 查看

```sh
python3 system.py --help
python3 system.py pools
python3 system.py validate
python3 system.py status
```

`pools`同时列池ID、旧/新价格、成员数。技能ID见`docs/技能池/`。状态默认使用`state/character.json`，同时刷新旁边的`character.md`。

## 击杀、抽取、选择、装备

以下是顺序操作示例，实际执行会改变正式存档。请只记录真实剧情战斗。

```sh
python3 system.py kill 初级兽将 10 --event ch001-battle-01
python3 system.py draw metal
python3 system.py choose 1
python3 system.py status
```

从面板读取实际获得的ID，再执行`python3 system.py equip 实际技能ID`。`equip`不随机、不升级，只装备已经拥有的技能。`unequip 实际技能ID`卸下；卸下不退款、不遗忘等级。

选择编号从1开始，与本次候选显示顺序相同。只剩一个候选时执行`choose 1`。再次`draw`时若仍有待选候选，会拒绝；用`status`找回候选。

## 首次行星级及扩槽

```sh
python3 system.py upgrade-planetary
python3 system.py unlock-slot main_earth_end
```

第一条代表作者确认境界突破，仅可一次；第二条代表确认主线完成，仅可一次。两者独立，突破不自动扩槽。

## 特殊奖励

```sh
python3 system.py draw blade --reward-token 主线奖励-001
python3 system.py choose 2
```

仅作者已确认获得特殊奖励时使用。免费三选一，奖励编号不可重复；普通抽取保持付费二选一。

## 独立试抽，不动正式存档

`--state`是全局选项，放在子命令之前。创建专门测试存档，然后每条试抽命令都带相同路径：

```sh
python3 system.py --state /tmp/swallow-demo.json init
python3 system.py --state /tmp/swallow-demo.json kill 初级兽将 10 --event demo-01
python3 system.py --state /tmp/swallow-demo.json draw metal
python3 system.py --state /tmp/swallow-demo.json choose 1
python3 system.py --state /tmp/swallow-demo.json status
```

若该文件已存在，`init`拒绝覆盖。需要全新试验可换一个新路径。每份存档有独立积分、已获得技能、候选和历史。

## 文件维护

```sh
python3 system.py render
python3 -m unittest discover -s tests -v
```

第一条从JSON更新文档和报告，第二条使用内存或临时目录测试，不改正式存档。`init`也拒绝覆盖现有正式存档；项目已初始化，无须再执行。

`character.json`含完整账本、仓库等级、当前装备、扩槽记录、候选和抽取历史；请将它与当时三份数据JSON一起备份。`.lock`文件是文件锁载体，空文件正常，无需删除。
