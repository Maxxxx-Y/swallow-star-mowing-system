# 空间法则

定位：轨迹偏移、位移、区域封锁
抽取价格：1000旧积分 / 1新积分；12项，同池等概率。

## 空间裂刃（space_01）

主功能：攻击；所属池：space、blade
触发：被动，条件满足时生效。
共同条件：具备对应武器、材料或器官；法则、灵魂、意志、神体相关机制需已有对应力量；技能提供方法，不创造力量；仅装备时生效；被动需持续装备；脱下后所有由此技能维持的效果、契约与分身暂停作用，不返还消耗。

|---|---|

| Lv2 | 已有空间感悟所允许的刀光切割效率提高10%。 |
| Lv3 | 已有空间感悟所允许的刀光切割效率提高15%。 |
