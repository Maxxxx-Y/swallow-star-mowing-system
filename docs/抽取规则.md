# 抽取规则

1. 选择一个技能池。普通抽取消耗该池当前币种价格，无品质、无权重、无融合。
2. 从该池所有“角色未拥有或拥有但未满Lv5”的唯一技能ID中，无放回、等概率抽2个不同候选。技能在其他池出现，不增加它在本池的权重。
3. 候选产生时立即扣款并保存；普通退出、关闭终端、再次启动都保留原候选。未完成选择前不得再次抽取，不能付费或免费重抽，也没有取消退款。
4. `choose 1`或`choose 2`选择一项。未拥有则Lv1，已拥有则升1级。另一项不消耗、不移出。
5. 达到Lv5后，同ID立即从所有所属池的可抽候选中移出。仓库里的满级技能也移出，不要求装备。
6. 候选仅剩1项时，仍按原价提供单选；0项时拒绝抽取且不扣积分。不暗补新技能、不返还此前抽取消费。

一个池当前有N个候选，普通二选一时，任意特定技能出现在候选中的概率为`min(2,N)/N`；每对无序候选的概率为`1/C(N,2)`（N≥2）。选择哪一项是作者决策，不是再次随机。

## 共享ID与技能仓库

`data/skills.json`中的每个ID只有一条权威记录。`pools`数组指定所有归属，池配置中不复制技能效果。例如`metal_04 锐金连斩`同时属于金之法则与刀法，两处得到的是同一技能；跨池抽中仍只升级同一个等级。

获得技能时一律入库，不自动装备。仓库不设容量，仓库技能不能提供任何增幅。装备技能受技能槽限制，满槽必须先卸下再换装。升级已装备技能时当前效果随等级更新；卸下不会丢失等级，也不返还积分。

初始3槽。只有配置中的稀少主线里程碑才能扩槽；不是击杀、升级或付费自动扩槽。主线事件只能领取一次。

换装视作战斗外操作，需要10秒连续安全整理时间；战斗中不得瞬时轮换仓库技能。因本工具不模拟战斗，整理时间由作者记录。卸下技能时，其持续场、盾、分身、契约增益与长期训练增量暂停生效；不得靠换装保留被动或契约名额。重新装备还需满足对应冷却，不允许卸下重装刷新冷却。

## 特殊三选一

仅实际获得剧情奖励时使用`draw 池ID --reward-token 奖励编号`，不扣积分，抽3个不同候选；不足3项时按实际候选数提供选项。每个奖励编号只可用一次，候选生成时就占用编号。

奖励是否发生由作者确认，脚本不自动发奖励。此命令属于作者授权记账入口，不是额外随机掉落率。普通抽取没有三选一开关。

## 随机与存档边界

正式抽取使用Python `secrets.SystemRandom`调用操作系统随机源，没有设种子、预览后反悔或按剧情改结果的入口。一次普通抽取仅抽一个池，不会把所有池先抽一遍再挑。

抽取记录保存候选、池、池内候选数、价格、时间、技能库/配置SHA-256摘要、选择前后等级。待选期间改动技能库或配置会阻止结算；请恢复对应版本，结算后再改。存档以临时文件加原子替换写入，macOS/Linux文件锁避免两个进程同时覆写。

这是本地、可编辑的作者工具。手动恢复旧存档或修改JSON仍能改变结果；摘要和日志用于自查与追溯，不构成防作弊或外部公证。脚本不向外部服务上传任何角色信息。
