# 数值规范

## 固定效果和共同基准

每个技能在JSON里保存完整五级效果文本与数字参数，不靠抽到后临时解释“少量”“大幅”等词。等级表示方法熟练度；境界与已有力量决定基础规模。原著未给出的技能均为本同人自设，不把技能等级当成法则感悟、修为或真神资格。

- `R`：不装备任何系统技能时，使用者对应能力安全可控的基础作用距离。未掌握对应远程能力时以臂展作为R；这不赋予尚未具备的法则力量。
- `B`：使用者当前阶段最大可用战斗能量的10%，代表单次主动技能的能量预算。可用能量不足B时不能施展，不透支。当前上限随真实境界、身体及可用力量改变。
- 同时有原力、念力、神力等能量时，按技能使用的那一种能量独立算B，不能跨种类重复领取预算。一次组合只注入一份共同预算B，所有联动消耗从该预算扣除；主动单独释放另付B。
- 默认主动技能冷却8秒，从释放开始计。文本给出特定冷却、准备时间、每次触发间隔时，特定规则优先。纯被动无额外主动冷却；触发型恢复、反伤使用其专有时间窗口。
- 投射物、轨道、连击、穿透、弹射、爆炸、持续伤害共用本次实际注入预算，不按次数复制B。基础伤害由自身力量、目标防御及实际分到的能量决定，数量增加不直接等于总伤害翻倍。
- 控制/束缚最多处理目标数不是保证控制成功；所有目标分别抵抗，总预算按目标数分摊。文本未另说明的控制持续2秒，范围≤R。

R以及自身基础能量属于主角正常世界观能力，需要作者在战斗场景确定一次后保持一致。本项目不是完整战斗引擎，没有预设主角尚未确定的米数、伤害面板或法则境界。

## 增益及数值上限

所有百分数参数使用百分数单位：`5`表示5%，不是500%。`radius_factor=0.5`表示0.5R；`dodge_bonus_pp=5`表示增加5个百分点。

| 类别 | 单技能/单次限制 | 同类累计限制 |
|---|---|---|
| 普通效率、速度、精度及范围增量 | 满级最多50% | 同指标相加，最多50% |
| 百分比减伤 | 单技能最多25% | 对同一次伤害适用项相加，最多50% |
| 能量消耗降低 | 单技能最多25% | 同一消耗相加，最多50% |
| 系统闪避增量 | 单技能最多10个百分点 | 合计最多30个百分点；最终概率最高80% |
| 减速 | 单技能最多25% | 同类相加，最多50% |
| 反伤 | 对指定已承受/已格挡能量的最多25% | 全部反伤共享每秒一次触发，总输出最多B |
| 击杀能量恢复 | 每次最多最大能量5% | 所有击杀恢复共享滚动10秒5%上限 |
| 肉身/战兽修复 | 单技能每秒最多目标最大生命1% | 同一被治疗目标共享滚动10秒5%上限 |
| 吞噬/材料提炼 | 材料实际可用能量×转化率 | 与其他外来能量恢复共享滚动10秒5%上限 |

表中限制只针对系统带来的增量；生命与能量不能超过真实容量。减伤先判定是否符合技能保护类型，再将符合项相加统一结算，不先逐层减伤再乘一次。控制时间不叠加，取最长剩余时间；同一目标受连续控制6秒后，之后6秒免受本轮同类强制控制，不能靠重复刷新无限困住。幻象数量只提供误导角度，不保证降低命中。

叠浪、连续发劲以未叠层基准计算：每层最多10%、最多3层，共30%；三层不是1.1³。其他同指标效率提高再相加，仍受50%系统增量上限。

身体振幅与灵魂振幅以不含系统技能的真实训练基准计算增量，只合并到对应原有指标一次。基因潜力开发上限是原训练基准的10%，且须资源和训练达标；它不是直接送10倍基因。同一指标仍受世界观相应上限限制，不能凭技能自动越过基因/振幅上限，也不另叠一个独立伤害倍率。

## 循环与特例

弹射每跳只传递剩余能量，且仅命中未被本次弹射命中的目标；不会在两怪之间无限跳。火系余烬仅转移目标尚未消耗的燃烧预算，该余烬不会再次触发余烬。反伤支付自身等量能量，不再触发反伤、击杀恢复或额外积分。

生命分身与本体共享原有总生命、能量、输出预算及同一套技能槽。数量不创造副本技能槽，不能借分身绕过同类上限。分身仅执行预设动作，不自动拥有独立修炼增长，永久真分身留待后续版本。Lv1–Lv5分别为1具20秒、1具30秒、2具40秒、2具50秒、3具60秒。

灵魂/驯兽契约需目标自愿或抵抗失败，且目标层次不高于自身。战兽必须实际存在，不自动召唤免费战力；协击消耗战兽真实能量，多兽不复制一兽的完整输出。契约数是本技能维持上限，不能卸下后保留系统控制再重新签一批。灵魂契约和驯兽契约对同一目标不得重复叠加控制。

空间与时间技能、神体、神力输出、灵魂转移和意志攻击，均需先具备对应力量。早期抽到可保留并升级，但未满足条件部分不生效；Lv5也不直接获得瞬移、时间回溯、神体、不死、意志越阶碾压或原著高阶秘术。灵魂转移只能使用预先兼容空置载体，不能湮灭后复活。技能提供方法与利用效率，不直接提供境界、感悟或兼容材料。

恢复、吞噬、药剂、替身和盾均需真实储备/材料。多种修复共享上限；本源永久损伤、灵魂湮灭不能按普通回血处理。满血/满能量的溢出恢复丢弃，不转成积分或永久容量。

所有规则优先级：本规范的总预算、世界观资格及共享上限 → 技能具体条件和冷却 → 默认主动预算与8秒冷却。修改规则要先更新版本，不针对一次抽取临时改效。
