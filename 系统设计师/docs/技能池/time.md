# 时间法则

定位：节律、延迟、行动窗口
抽取价格：1000旧积分 / 1新积分；12项，同池等概率。

## 迟发刃（time_01）

主功能：攻击；所属池：time、blade
触发：主动或所述条件触发。
共同条件：具备对应武器、材料或器官；法则、灵魂、意志、神体相关机制需已有对应力量；技能提供方法，不创造力量；仅装备时生效；被动需持续装备；脱下后所有由此技能维持的效果、契约与分身暂停作用，不返还消耗。

| 等级 | 固定效果 |
|---|---|
| Lv1 | 预付攻击能量后延迟释放一次斩击，延迟0.2秒；距离≤R，释放前可被打断，打断后预付B损失，无时间回溯或额外攻击次数。 |
| Lv2 | 预付攻击能量后延迟释放一次斩击，延迟0.4秒；距离≤R，释放前可被打断，打断后预付B损失，无时间回溯或额外攻击次数。 |
| Lv3 | 预付攻击能量后延迟释放一次斩击，延迟0.6秒；距离≤R，释放前可被打断，打断后预付B损失，无时间回溯或额外攻击次数。 |
| Lv4 | 预付攻击能量后延迟释放一次斩击，延迟0.8秒；距离≤R，释放前可被打断，打断后预付B损失，无时间回溯或额外攻击次数。 |
| Lv5 | 预付攻击能量后延迟释放一次斩击，延迟1秒；距离≤R，释放前可被打断，打断后预付B损失，无时间回溯或额外攻击次数。 |
