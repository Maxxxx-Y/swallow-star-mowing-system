# 设定管理员

负责读取小说设定、追踪人物状态、更新大纲、检查前后矛盾。不擅自改动已经确定的核心规则。

## 本目录

- [角色状态](state/character.md)：日常查看积分、已获得技能、装备和待选候选。
- [正式角色存档](state/character.json)：程序保存的唯一状态源，包含完整收支和抽取历史。抽奖执行器负责写入，设定管理员读取并用于核对剧情；不另复制一份可变账本。
- [初版交付及取舍记录](交付记录.md)：确认过的规则、占位事件和设计来源。

小说正文、人物档案、大纲和矛盾记录目前尚未提供；以后直接放入本目录，不预填剧情或人物经历。

## 工作边界

已确认的系统规则由[系统设计师目录](../系统设计师/README.md)集中保存。管理设定时可以指出冲突并提出修改建议，核心规则调整必须先经作者确认。角色抽取结果通过[抽奖执行器](../抽奖执行器/README.md)产生，不根据情节需要手改结果。

修改Markdown面板不会修改正式存档；面板由程序从JSON生成。查状态可在项目根目录运行`python3 抽奖执行器/system.py status`。
